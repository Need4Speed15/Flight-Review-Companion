Arithmetic checks, with newly supplied values explicitly described as training/hypothetical:
- Oxygen duration: 100 minutes full-bottle chart value x 0.60 usable capacity = 60 minutes. Actual duration requires the installed-system chart and proper mask/user count.
- Approximate pressure altitude: 5000 + (29.92 - 29.62) x 1000 = 5300 feet.
- Cumulative climb-fuel difference: 300 - 40 = 260 pounds, not the full cumulative 300.
- Cruise fuel: 180/240 hours x (270 x 2) lb/hr = 405 pounds. Separate engine flows must be summed.
- Full plan: 90 + 230 + 900 + 130 + 350 = 1700 pounds; 1610 is short by 90. Reserve is an exercise assumption, not a statement of applicable regulations.
- Handbook landing-weight example: 12590 - 1653 = 10937 pounds; total burn already includes ground use.
- Cruise segment: 600 - 70 - 60 = 470 NM, excluding separately modeled climb/descent distances.
- Groundspeed revision: 400/250 x 500 = 800 pounds versus 400/200 x 500 = 1000 pounds.
- Added baggage: (12000 x 193 + 100 x 325)/12100 = 194.0909 inches. A computed CG alone does not establish compliance with all limits.
- Moved occupant: 200 x (250 - 129)/12000 = 2.0167 inches aft, unchanged total weight. Actual seating/configuration must match the station table.
